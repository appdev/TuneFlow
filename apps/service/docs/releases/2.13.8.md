# TuneFlow 2.13.8

本次服务端更新整合共享平台账号与访问密码，供桌面、Web 和 Android 使用。

- 新增统一的账号状态、官方扫码、歌单、导入、个人推荐及收藏接口，平台读取逻辑提取至共享代码。
- 支持共享访问密码、记住设备会话、退出和密码变更撤销；现有授权、平台账号和音乐数据保留，密码首次设置需已授权客户端或停服后的本地管理命令。
- 密码仅保存加盐 scrypt 哈希，账号凭据保存在配置目录的加密存储；保留请求来源、限流、账号修订、会话及导入完整性校验。
- 默认 Web 同步更新侧栏线性图标和协议流程：确认倒计时 10 秒，移除接受后的额外提示；`/V2/` 继续可用。
- Docker 构建包含账号读取运行依赖及运行文档，配置和音乐挂载方式保持不变。

账号接口的访问控制不会改变原有音乐、音乐库等接口的共享实例策略。详细初始化与恢复方式见 [平台账号说明](../platform-accounts.md)。

镜像发布到 Docker Hub：`apkdv/tuneflow-server:2.13.8`（linux/amd64）。此发布不自动升级已有容器，更新时继续使用原 `/config` 和 `/music` 挂载并保留备份。
