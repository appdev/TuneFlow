# TuneFlow 2.13.7

本次版本将服务端、桌面、Web 和 Android 的源码统一到 TuneFlow 仓库，各端继续独立构建和发布。

- 服务镜像默认提供共享 Web，浏览器自动连接当前站点，并隐藏服务器切换设置；原界面保留在 `/V2/`。
- 优化 Web 居中布局、两侧背景与页面边缘衔接。
- 更新产品介绍、安装与开发说明，补充 Web、Android 实际界面截图。
- 保留现有配置、音乐库、歌单、应用标识及更新兼容规则。

对应客户端源码版本为 `0.4.25`。当前 Docker Action 构建 `linux/amd64` 镜像；此文档和版本提交不代表镜像已经发布，也不会升级运行中的容器。

正式发布前需通过容器健康和存储检查。更新时继续挂载原 `/config` 和 `/music`，先保留备份；需要回退时使用上一版本镜像，不覆盖现有数据。
