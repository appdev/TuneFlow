# TuneFlow 2.13.10

本次发布 Docker 镜像及内置 Web；桌面与 Android 安装包、现有 Release 附件和公开更新通道保持不变。源码版本按现有发布校验统一为 2.13.10。

- 新增 `TUNEFLOW_ACCESS_PASSWORD` 环境变量，首次启动自动初始化 8～128 个字符的共享访问密码。容器管理面板添加环境变量即可，无需离线初始化命令。
- 已有密码时忽略环境变量，重启不会覆盖在应用中修改的密码。非法初始密码会阻止启动，错误信息不包含密码值。
- 保留平台账号、歌单、音乐和历史记录；首次初始化会撤销旧访问会话。忘记密码仍可使用离线恢复命令。
- 同步三端的首次设置提示，并补充 Docker run、面板与 Compose 使用说明。
- 发布流程支持显式选择 `docker_only=true`；镜像通过首次登录、修改密码和重启保留密码的检查后才允许发布。默认完整发布流程不变。

升级已有容器时保留原 `/config` 与 `/music` 挂载。环境变量只用于首次初始化，不用于重置已有密码；容器管理员可查看环境配置。

发布状态：本标签的发布任务已取消，未推送镜像。完整业务改动随 2.13.11 发布，保留此标签用于追溯。
