# TuneFlow 2.13.12

本次发布 Docker 服务镜像与内置 Web。连接服务后直接使用共享平台账号，无需再初始化访问密码或解锁设备。桌面与 Android 源码同步更新，安装包和公开客户端更新通道保持不变。

- 移除共享访问密码、密码设置与修改界面、设备授权令牌及离线密码恢复命令。旧的 `TUNEFLOW_ACCESS_PASSWORD` 环境变量不再生效。
- 移除共享账号接口的 Origin 限制，中转和反向代理无需配置可信域名、代理 IP 或专用转发头。
- 账号数据直接保存在 `/config/account-security/accounts.json`。升级时用原有 `vault.key` 自动读取 `vault.enc`，迁移平台登录状态并保留原文件，无需输入密码或手工解密。
- 保留平台授权校验、账号版本冲突检查、扫码取消与过期处理和请求频率限制；多个客户端的二维码不会互相取消。
- 简化 Docker 启动命令与飞牛等管理面板配置说明，部署与发布测试改为验证无密码访问和重启持久化。

升级时复用原 `/config` 和 `/music` 挂载；访问权限由部署者自行管理。若回退旧镜像，旧保险库保留的是迁移前状态，之后新增或更改的账号状态仅在 JSON 文件中，请备份完整配置目录。

源码统一版本为 2.13.12，Android versionCode 基数为 59。本次仅发布 Docker，不发布客户端安装包。
