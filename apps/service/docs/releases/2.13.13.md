# TuneFlow 2.13.13

桌面、Web、Android 与 Service 统一升级，沿用现有应用标识、账号、歌单和设置。本次提供 Docker 镜像和各平台客户端预览包。

- 桌面与 Web 重排顶部导航与搜索，收紧来源选择菜单，优化设置、下载、排行榜和我的列表。
- 歌单和推荐详情使用紧凑封面布局，统一歌曲行高和滚动条留白，为列表保留更多可用空间。
- 新安装默认使用经典蓝白，提供浅色、深色及系统外观；已有主题偏好保持。
- Android 手机端新增底部导航、双列歌单、榜单预览和分组设置，调整迷你播放器、播放详情与下载列表；平板和车机保留原有布局。
- 修复手机设置返回目录后的重复跳转，清理深链参数日志，并修正 Android 类型检查和离线验收工具。

Android versionCode 基数为 60。升级复用原配置和音乐目录；本次未变更存储格式。回退可使用上一版本的安装包或镜像，回退前保留完整配置备份。
