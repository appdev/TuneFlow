# TuneFlow 2.13.14

桌面、Web、Android 与 Service 同步升级，沿用现有应用标识、账号、歌单和设置。

- macOS 状态栏新增可直接点击的上一曲、播放／暂停、下一曲实心图标；新安装默认开启状态栏图标，已有开关选择保留。
- 开启 macOS 状态栏歌词时自动启用关闭主窗口后保持后台播放，并保留桌面歌词的显示、锁定与置顶控制。
- 桌面与 Web 统一使用新版界面，清理旧前端与重复图标，沿用紫色音符应用图标；继续优化搜索、歌单列表与空状态。
- 修正 macOS 安装包原生依赖的架构准备与校验，减少跨架构组件混入安装包。
- Service 改用独立音乐 SDK，补齐共享 Web 的实际播放、下载及音乐库验证。

升级说明：旧 Web 的 /V2/ 入口已移除，请使用站点根路径访问。桌面和 Android 继续沿用现有预览包身份与签名，覆盖安装即可。

Android versionCode 基数为 61。存储格式未变更；回退前保留完整配置备份，可使用上一版本安装包或镜像。
