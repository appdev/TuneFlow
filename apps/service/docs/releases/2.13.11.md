# TuneFlow 2.13.11

本次提交当前完整业务改动，并发布 Docker 服务镜像及内置 Web。桌面与 Android 安装包、已公开 Release 附件和客户端更新通道不变。2.13.10 发布任务已取消，其标签保留用于追溯。

- 通过 `TUNEFLOW_ACCESS_PASSWORD` 环境变量首次设置 8～128 个字符的共享访问密码，无需离线初始化命令。已有密码时忽略该变量，保留应用内修改后的密码；非法初始配置阻止启动，日志不包含密码值。
- 保留平台账号、歌单、音乐和历史记录；首次初始化撤销旧访问会话。忘记密码仍使用离线恢复命令。
- 统一桌面、Web、Android 的列表字号、文字层级、颜色和选中态，简化重复的平台图标，调整下载、歌单、专辑和播放队列的展示；同步项目图标与维护说明。
- 纳入 `apps/cli` 的 AI 工具命令行源码：默认 JSON 输出，支持结构化搜索、音乐库和歌单、后台播放、队列、进度监听及下载；复用共享 Service，播放依赖本机 mpv。CLI 从源码独立构建，不包含在 Docker 运行镜像中。
- 发布流程支持 `docker_only=true`，验证首次密码登录、修改密码和重启后的密码保留后才发布镜像。

升级已有容器请复用原 `/config` 和 `/music`。源码版本统一为 2.13.11；Android versionCode 基数为 58，此次不发布客户端安装包。
