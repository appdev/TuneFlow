TuneFlow 0.4.26

本次发布桌面、Web、Android 与统一音乐服务的整合预览版本，客户端发布与更新统一迁入 TuneFlow 仓库。

- 平台账号、账号歌单和个人推荐接入共享服务，各端使用同一账号状态；保留原生官方登录及已有账号迁移入口。
- 新增共享访问密码和记住登录，支持退出当前会话、修改密码后撤销其他会话；已有账号、歌单和下载文件保留。
- 统一服务端平台读取与账号校验，保留歌单导入完整性、并发更新及账号变更保护。
- 优化侧栏图标与选中态，去掉图标方块和重阴影，支持浅深主题及键盘焦点提示；Android 横屏侧栏和竖屏抽屉同步调整。
- 协议确认倒计时统一为 10 秒，移除接受后的免费开源提示弹窗，保留接受后的初始化流程。

升级说明：

- 使用 TuneFlow-v0.4.26 标签。原 Q-music 发布仓库已删除，旧版请手动下载新包覆盖安装一次，无需卸载；新版使用 TuneFlow 更新通道。
- 桌面预览版应用 ID、配置目录及 Android 预览包名和签名保持不变。Android 为 0.4.26-preview，versionCode 基数 54，多数手机选择 arm64-v8a。
- macOS 为临时签名、未公证；Windows 为未正式签名的便携包；桌面预览包仍需手动替换应用。Web 包包含 /V2/ 兼容入口。
- 播放与下载继续使用统一服务，Docker 镜像单独发布至 Docker Hub。更新源码或安装包不会自动升级已有容器。
- 已有真实 QQ 与访问密码流程的验收结果不代表所有平台、设备均完成真实扫码验收；遇到官方安全验证需在对应平台处理。

Q-music 0.4.25

本次版本将桌面、Web 与 Android 纳入 TuneFlow 同一源码仓库，各端仍独立构建和发布，共享音乐服务和业务规则。

- 服务镜像默认提供共享 Web，浏览器自动连接当前站点；保留 /V2/ 兼容入口。
- 优化 Web 居中展示、两侧背景和边缘过渡，补充产品说明与 Web、Android 实际截图。
- 保留现有歌单、音乐库、设置、桌面预览数据目录、Android 预览应用 ID 和签名。
- Android 版本为 0.4.25-preview，versionCode 基数升至 53；升级时覆盖安装，无需卸载。

源码版本已升级不代表安装包或镜像已发布。客户端发布与更新统一迁至 TuneFlow，使用 TuneFlow-v<version> 标签；旧版需手动覆盖安装新版一次，无需卸载。具体构建与发布状态见多平台发布检查文档。桌面仍为预览便携包；macOS 尚未公证，Windows 未正式签名。播放与下载继续使用统一服务，现有功能边界不变。

Q-music 0.4.24

本次发布统一音乐服务整合版预览通道，桌面、Web 和 Android 使用同一套设置、歌单、音乐库与下载服务。

- 恢复平台账号登录、账号歌单导入与首页推荐，保留推荐来源、换批刷新、更新通知及推荐回退。
- 优化侧边页面切换、首页缓存与下载列表，返回页面时保留内容，减少重复加载。
- 恢复边播边存；下载支持明确删除音乐库文件，并在确认后替换已有音质，取消操作保留原文件。
- 可恢复的解析失败继续自动切换平台，播放与下载继续使用统一服务，保留原有安全限制。
- macOS 使用原生窗口控制按钮；跨端保留已有设置和歌单数据。

安装与兼容性：

- 桌面包沿用现有预览版应用标识和数据目录，更新时退出旧程序后替换应用，无需卸载。macOS 包为临时签名，尚未公证；Windows 包为未签名便携版；桌面暂不支持应用内自动安装更新。
- Android 沿用现有独立预览版包名及预览签名，版本 0.4.24-preview，versionCode 基数 52。请覆盖安装匹配 ABI 的包；正式版与预览版不能相互覆盖。
- Web 包包含主界面和 /V2/ 兼容入口，需要连接 TuneFlow 2.13.6 服务。官方账号授权需在原生客户端完成；浏览器使用共享歌单。
- QQ 真实登录已在桌面验收，Android 官方登录仍待设备验收。其他平台登录仍以实际平台授权结果为准。
- 本次只发布代码、安装包和镜像，不会自动升级线上容器。下载文件均附 SHA-256 校验，发布清单记录各端的源代码提交。

Q-music 0.4.23

本次正式版打磨 PC 的歌单与下载操作，并为 PC、安卓补上自定义日夜切换时间。

### PC 多选与歌单交互

- 歌单、在线歌曲列表和下载任务增加清晰的「多选」入口，支持逐首勾选、全选、反选，以及右键选中／取消选中；可使用 Ctrl／Command 和 Shift 选择多首或连续歌曲。
- 反选至空、取消最后一首后仍保留多选模式；多选时点击歌曲不会误播放，搜索输入框中的 Ctrl+A 仍用于选择文字。
- 左侧自建和导入歌单支持直接拖动排序，可将本地歌单拖到平台歌单上方；试听列表和我的收藏保持固定。
- 拖动增加轻微抬升、邻项弹性让位和落下回弹，顺序即时更新并保存；关闭动画或启用系统减少动态效果时使用简化反馈。
- 切换 QQ 音乐、网易云、酷狗等已导入歌单时复用列表页面，减少整页重建导致的闪动。

### PC 下载与文件处理

- 下载页统一使用「移除记录…」，确认框明确默认保留文件，也可勾选同时把音频与同名歌词移入回收站。
- 删除文件成功后同步清理各本地歌单中对应的文件引用，避免歌曲仍显示在列表；在线平台歌曲不受影响。
- 文件处理等待下载停止，沿用任务原有路径；删除失败时保留对应任务和列表记录，取消确认时保留已选歌曲。
- 修复 Windows 部分回收站操作失败，以及移除最后一条下载任务时的界面异常。

### PC 与安卓自定义日夜时间

- 在「设置 → 外观／主题 → 按时间」中，可分别设置白天、夜间开始时间，精确到分钟，支持跨午夜。
- 默认仍为 07:00／19:00；非法或相同时间会提示修正，保存后立即重新计算外观，重启和切换模式后保留设置。
- 自动切换明暗继续保留所选主题配色和背景。

### 安装与验证

- Windows x64、Arch Linux x64 和 Android 同步发布 0.4.23；安卓沿用正式版包名与签名，可覆盖升级，多数手机选择 arm64-v8a。
- 已通过相关回归检查，并在独立 PC 测试窗口验证多选、拖动持久化、回收站删除和自定义时间；安卓已完成相关自动化验证与构建，本次未连接真机。
