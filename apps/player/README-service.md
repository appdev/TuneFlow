# 统一客户端：桌面与 Web

[产品首页](../../README.md) · [桌面构建](README.md) · [Web 能力与构建](../service/docs/qmusic-web.md) · [Android](../android/README-service.md)

## 数据与执行归属

TuneFlow 是一个服务与多个客户端组成的应用。界面使用音乐库、推荐、下载和设置等业务名称；不再单列“Docker 音乐”工作区。

| 功能 | 归属 |
| --- | --- |
| 音乐库 | Server 的媒体目录；刷新执行服务端扫描 |
| 歌单、收藏、播放历史 | 同一 Server 的共享数据 |
| 搜索、榜单、歌单广场、解析与平台切换 | Service API；客户端展示并播放 |
| 下载与边听边存 | 服务执行，完成后进入同一音乐库 |
| 音源、解析顺序、下载设置 | 服务共享设置 |
| 外观、音量、音频输出、临时队列与恢复信息 | 客户端偏好；按服务地址隔离相关记录 |
| 桌面歌词、窗口、托盘、全局快捷键 | Electron 平台能力，Web 不提供 |

移除下载任务记录会保留已下载文件；删除音乐文件是单独的操作。连接同一个 Server 的 Android 使用同一份歌单和音乐库，不要求另外部署旧版点对点同步服务。

## 首页与账号

首页复用已加载的推荐和封面；主动换批、账号变化、连接变化、跨日或缓存过期时更新。未登录时优先展示所选平台公开精选，不可用时使用通用推荐；个人推荐与公开精选明确区分。

音乐平台官方授权由对应的平台适配器处理。已有账号歌单可显式导入统一列表，播放继续经过 Service。浏览器的官方登录及原生能力边界见 [Web 说明](../service/docs/qmusic-web.md)，账号功能以对应版本的发行说明为准。

## 连接与数据保留

桌面在连接设置中填写自己的 Server 地址；不把开发或测试机器的内网地址当作部署要求。Web 绑定页面 origin，既不读取桌面保存的地址，也不提供换服入口。

现有预览身份、profile 与数据键保持兼容。连接失败显示错误，不回退到旧本机数据库或本机音源；切换连接时释放旧会话，避免跨服务混用。旧本机文件、歌单与配置不会自动上传、覆盖或清空。

客户端安装、打包与测试命令见 [桌面 README](README.md)，共享契约与发布兼容见 [单仓库说明](../../docs/monorepo.md)。临时安装包与本地验收报告不作为仓库公开下载入口。
