音流免安装版 / TuneFlow Portable edition

解压整个压缩包后运行 Q-music.exe，无需安装。
保留此 portable 文件夹，程序会把设置和歌单保存在 portable/userData。
升级时退出程序，将新版解压到新文件夹，再把旧版 portable 文件夹复制过去。
请不要用新包里的 portable 文件夹覆盖旧数据。安装版不会自动迁移到这里。
本地音乐仍引用原文件路径；移动音乐文件后需要重新导入。

Extract the whole archive and run Q-music.exe. No installation is needed.
Keep this folder: settings and playlists are stored in portable/userData.
To upgrade, exit the app, extract the new version into a new folder, then copy
your existing portable folder into it. Do not overwrite your existing data
with the empty folder from a new archive. Installed-edition data is not migrated.
Local music references its original file paths. Reimport files after moving them.
