# 平板与安卓车机布局

- 设置 → 基本设置 → 屏幕布局：自动适配 / 手机 / 平板 / 车机，修改后立即生效并保存。
- 自动模式按可用窗口宽度布局，支持横竖屏、平板分屏。能被 Android 识别的车载设备自动启用车机控件；普通安卓车机可手动选择。
- 大屏使用带文字的侧栏；歌曲播放条在内容区域下方独立占位，不遮挡最后一首歌。窄窗口恢复底部导航。
- 足够宽时，我的音乐和排行榜采用左侧分类、右侧歌曲的双栏；设置分类与内容同屏。
- 播放详情在大屏同时展示封面与双语歌词，底部保留进度和播放控制，沿用封面动态背景。
- 车机模式增大歌曲条目至 72 dp，放大主要播放按钮并禁用首页左右滑动切页，减少横向误触。
- 宽屏首页将欢迎区与快捷操作并排，内容限定最大宽度；迷你播放条的封面、字号和按钮同步放大。
- 侧栏采用单层圆角选中态，设置分类保留固定箭头位置，切换时文字不跳动。双栏曲库隐藏重复的歌单抽屉入口。
- 大屏歌词区不再重复显示封面和歌曲信息；封面、曲目信息与收藏操作集中摆放，底部控制区使用独立圆角面板。

这里适配的是允许安装 APK 的 Android 车机和平板，不包含 Android Auto 投屏、CarPlay 或车厂系统集成。旋转遵循系统方向设置，账号、音乐源、歌单和播放能力与手机版相同。

验证：`node --test scripts/verify-adaptive-layout.cjs` 检查尺寸断点、键盘、分屏和模式覆盖；APK 还需在实际设备验证厂商系统栏、旋钮/方向盘按键及后台策略。

## 播放详情风格

播放详情右上角的设置按钮，或设置 → 播放设置 → 播放详情风格，均可切换：

- 原版（默认）：保留已有的方形封面、歌词排版、播放按钮、背景与动效，不替换成 PC 的唱片造型。
- Apple 沉浸：独立布局。手机使用带阴影的圆角方形封面、底部曲目信息和无圆底播放按钮，工具栏可切换封面／歌词，也保留左右滑动。平板与车机把封面、曲目信息、进度和控制集中在左栏，右侧为大字号歌词，不使用原版的底部控制面板和分栏线。双语译文使用更小字号，保留当前行与上下行的明暗层次。
- Apple 背景使用放大模糊的当前封面缓慢漂移和旋转，减少整页灰黑遮罩，呈现封面本身的颜色；没有封面时使用深色底。

两种风格共用播放、歌词、队列和设置逻辑，切换立即保存，不改变首页主题。手机、平板和车机使用同一选择，屏幕布局独立适配。Apple 风格在流畅模式下关闭模糊背景与装饰动画；系统减少动态效果时停止背景漂移。应用进入后台或播放页不可见时不运行 Apple 背景动画。原版背景使用原有实现。
