# 歌单来源与 QQ 同步

手机、平板与车机共用歌单来源组件：账号导入的 QQ 音乐、网易云音乐、酷狗音乐歌单显示各自图标和来源文字。歌曲列表标题、单曲收藏及批量收藏的目标也保留平台标识。同名歌单不依赖名称猜测来源；没有来源记录的历史歌单继续标为本地。

「我的 → 歌单同步」和歌单侧栏的「同步」进入同一面板，可查看最近同步时间、手动同步和一键同步 QQ 歌单。网易云与酷狗仍可单独手动更新。

新导入的独立 QQ 账号歌单默认自动更新。旧歌单先手动同步绑定当前账号，再开启自动更新。应用在前台每 10 分钟检查，回前台补查；后台不运行轮询。QQ 的新增、移除和顺序会覆盖关联的本地歌单，本地编辑不会上传。

单曲收藏窗口可将 QQ 来源歌曲收藏到官方「我喜欢」。账号身份及真实歌曲 ID 经核对后只提交一次，回读确认后才显示成功；未知结果提供只读核对。成功后刷新同账号、开启自动更新的本地「我喜欢」，等待此前同步结束再读取最新数据。

不完整分页、账号变化、取消、列表删除或重新关联时，不覆盖原歌单。写入成功后才记录同步时间。账号归属不包含会话令牌。PC 与安卓分别保存自身的绑定记录，不将一端的绑定标记直接当作另一端的授权。

## 本地验证

- `npm run test:accounts`：账号读取、分页完整性与导入保护。
- `npm run test:qq-sync`：收藏签名、写后回读、重复请求、账号绑定、同步取消和前台调度。
- `node --test scripts/verify-adaptive-layout.cjs`：手机、平板与车机自适应规则。

这些回归使用本地模拟响应，不代替真实账号和厂商系统上的最终验证。
