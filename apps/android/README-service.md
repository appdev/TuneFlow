# 统一客户端：Android

[产品首页](../../README.md) · [Android 构建](README.md) · [桌面与 Web 数据归属](../player/README-service.md)

Android 连接与桌面/Web 相同的 TuneFlow Server，使用同一份歌单、收藏、历史、音乐库、音源和下载设置。音乐解析与自动切换平台由服务处理，手机负责音频播放与系统媒体控制。

## 业务与设备边界

- 音乐库展示服务管理的文件；刷新不会打开手机目录选择器或自动上传旧文件。
- 下载与边听边存由服务执行；移除任务记录保留文件，删除音乐另行操作。
- 首页支持平台精选、可用的个人推荐与通用回退，普通页面切换复用缓存。
- 外观、音量、输出、后台播放、歌词与临时队列属于设备偏好。
- 官方账号授权按平台适配器处理；同步歌单不应被理解为自动完成另一台设备的官方登录。

业务功能默认与桌面/Web 对齐；通知权限、WebView 授权、媒体会话和后台生命周期等由 Android 实现。旧同步协议属于兼容能力，连接同一 Server 不需要额外部署同步服务。

## 数据与连接兼容

在连接设置中填写自己的服务地址。切换前验证连接、停止旧播放并释放旧列表与搜索状态；断线显示错误，不切回旧手机数据库或手机音源。取消与安全拦截不会被解析回退绕过。

现有手机文件、歌单、音源脚本和配置保留，不自动上传或清空。使用同一预览应用 ID 和签名覆盖升级；正式通道与预览通道不能混用。测试地址、临时 APK 路径和历史验收次数不作为安装说明。

构建、签名与验证命令见 [Android README](README.md)，仓库边界与发布流程见 [单仓库说明](../../docs/monorepo.md)。跨端测试从当前仓库的 `apps/player`、`apps/android` 与 `apps/service` 加载实现，不再依赖相邻独立仓库。
