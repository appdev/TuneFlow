# Q-music 统一 Docker 客户端 · Android

最新首页优化包位于 `artifacts/home-unified/Q-music-home-unified-arm64-v8a.apk`，需要 Android 7.0 以上的 ARM64 设备。内部版本号沿用 0.4.23-service.5，预览包名仍为 `io.github.nshpiter.qmusic.mobile.preview`，使用测试签名，可与正式版共存；覆盖安装保留预览版数据。此前安装包保留。

## 统一后的入口

桌面、Web 和 Android 默认提供相同业务功能，共用 Docker 服务。新增功能和修复须同时检查三端；仅平台无法支持的能力保留明确说明。

界面统一使用音乐库、推荐、下载和设置等名称，不再按 Docker 与设备拆分入口。未登录时优先展示所选平台的公开精选，平台接口不可用时使用通用推荐；已登录账号的个人推荐仍优先，公开内容不会标成个人推荐。

首页与各推荐来源保留快照，普通导航、前后台切换及返回已加载来源不重新请求。主动换批、账号或连接变化、日期变化、缓存过期时更新；通用推荐更新事件只使通用快照失效。快照按连接、平台与账号隔离，正常有效期为 15 分钟，准备中的推荐短暂缓存。

已移除“Docker 首页 / 手机首页”切换。原生搜索、歌单广场、排行榜、我的音乐、收藏弹窗和播放器直接使用 Service。专辑搜索加入同一搜索分类；每日推荐可选择服务器或已登录的平台账号。

“我的音乐 → 音乐库”指 Docker 媒体目录。刷新操作扫描服务器，不选择手机文件。收藏、歌单与播放历史和桌面端共享；下载在 Docker 执行，完成后进入同一音乐库。移除任务保留已完成文件。

“设置 → 下载”提供“边听边存（播放时自动下载）”。该开关三端共享，在线歌曲实际开始播放后按最高可用音质保存；重复播放复用下载，曲库歌曲不再次下载。它独立于手动下载的“启用下载”开关，现有开关值保留。

设置内统一提供“服务器连接”“音乐平台账号”“音源与解析”“下载 · 服务器”。QQ 音乐、网易云与酷狗在当前设备登录；凭证仅留在设备，Docker 不托管账号。账号歌单显式导入到服务器，与桌面使用同一标识；重复导入追加歌曲并保留服务器已有内容，切换账号或服务器会停止后续写入。个人推荐不可用时明确显示服务器推荐，播放统一走 Docker。

外观、音频输出、后台播放、歌词、播放音质和临时队列仍属于当前设备。云盘、旧版同步与远程备份集中说明，不显示成可配置服务器的功能。

按用户选择，平台凭证直接写入 App 私有的 no-backup 目录，不再为新凭证生成或使用 Android Keystore 密钥。旧加密记录可读取时自动迁移；无法解密时原文件保留，可重新授权。退出账号会清除当前和旧凭证，避免重新恢复已退出的会话。网页登录 Cookie 仍由 App 内的 WebView 管理。

## 数据保留与连接

旧手机歌单、文件、配置和音源脚本保持原样，不自动上传或清空。服务器列表只更新内存视图，不走旧手机数据库写入或点对点同步。列表状态和播放恢复数据按服务器地址另存，避免覆盖旧记录。

默认地址为 `http://192.168.0.70:3124`。切换服务器前验证连接，停止旧播放、释放旧列表和搜索缓存。断线显示错误并允许重连，不切回手机数据库或手机音源。安全拦截和取消不会被平台回退绕过。

## 构建与验证

```sh
Q_SERVICE_ROOT=/path/to/TuneFlow npm run test:service
node_modules/.bin/tsc --noEmit -p tsconfig.json
npm run pack:android:standalone -- -PreactNativeArchitectures=arm64-v8a
# 主机 Java 存储测试需要 JDK 和实际 org.json 运行库（不能使用 Android stub jar）
Q_MUSIC_JSON_JAR=/path/to/json.jar npm run test:credential-storage
```

跨客户端统一适配测试在相邻 `../qmusic-desktop` 执行 `npm run test:service`，会加载两端真实适配器并启动独立临时后台。覆盖账号歌单追加导入与重复导入、凭证字段过滤、歌单/收藏共享、曲库标识往返、下载保留文件、设备队列隔离、设置/历史，以及酷我解析失败后切换网易云读取音频流。

Android 原有 TypeScript 全量检查有 15 项既存错误；本轮需要确认无新增错误，不能将全量检查描述为通过。APK 构建与模拟器流程证据见 `artifacts/home-recommendations/verification/`。模拟器验证不代表已在实体手机上测试。

本轮各项测试和真实账号验收范围以本版验证记录为准。桌面完成 QQ 登录不会自动授权 Android；Android 登录需要在该设备的官方页面完成，账号凭证不会随服务器歌单同步。

## 首页推荐恢复（service.5）

复用原版推荐展示：四格封面、日期、来源说明、前九首“今日发现”、专用详情、播放/暂停、加载骨架及日推设置入口。个人推荐优先，失效时回退 Docker；显式选择服务器推荐的现有偏好保留。封面与播放均走既有 Service 适配层。

主页刷新与详情下拉刷新均绕过账号推荐缓存；需要服务器回退时调用后台换批接口。普通刷新失败保留当前结果，切换来源、账号设置返回或服务器变化时释放旧视图。五秒事件快照轮询接上推荐更新，其他客户端触发换批后自动更新。没有迁移、清空账号凭证或本机/服务器歌单；覆盖安装使用原预览包名和签名。

真实 Android 平台登录继续按用户要求待验收；桌面授权不会自动登录手机。
