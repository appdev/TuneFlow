# TuneFlow 2.13.6

本次版本整理统一音乐服务接口，供桌面、Web 和 Android 使用。

- 完善可恢复解析失败的跨平台自动切换，保留来源访问、匹配和安全限制。
- 支持统一的下载、边播边存、音乐库删除及确认后的音质替换；替换失败保留原文件。
- 统一账号歌单、推荐回退和客户端同步所需接口，保留现有配置、音源、歌单和音乐文件。
- 发布镜像前执行容器健康检查及配置／音乐目录归属检查，附带版本、提交和镜像摘要清单。
- Web 构建清单改为读取客户端版本，避免显示旧版本号。

镜像：`apkdv/tuneflow-server:2.13.6`（linux/amd64）。

此 Release 发布代码和镜像，不会自动升级正在运行的容器。更新时继续挂载原配置及音乐目录；升级前保留备份，可切回原版本镜像。容器默认 Web 入口沿用原界面，Q-music Web 作为客户端独立提供。
